# Center navigation on the Library

The initial product opens Library Search after sign-in. Persistent navigation exposes Library Search, Discogs Import, Add Manual Track, and Backup/Restore. Track details and Transition creation are contextual screens reached through Library Tracks rather than additional top-level destinations.

## Consequences

The fastest path in both set preparation and live use begins with locating the Track that is currently playing. Mobile and desktop layouts may present the persistent navigation differently, but they retain the same information architecture. The initial product does not need separate top-level views for all Transitions, incoming Transitions, or outgoing Transitions.
